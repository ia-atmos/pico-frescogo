- Editar os caminhos em `frescogo.desktop` (o `frescogo.sh` acha o
  repositório sozinho).
- Copiar `frescogo.desktop` para o diretório `home/Desktop`.
- Right-click no ícone e selecionar "Allow Launching".
- Criar link para `relatorios/`.

O `frescogo.sh` roda o placar em Atmos (`make frescogo`, na raiz do
repositório, e depois `./frescogo`). Ver `PORT.md`.
